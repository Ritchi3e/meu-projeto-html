Aula 02 - Introdução ao CSS

O que é CSS

CSS (Cascading Style Sheets) é a linguagem usada para estilizar páginas HTML: cores, fontes, espaçamento, layout etc. Enquanto o HTML cuida da estrutura e do conteúdo, o CSS cuida da aparência.

Como conectar o CSS ao HTML

A forma mais organizada é criar um arquivo .css separado e linká-lo dentro do <head> da página:

<link rel="stylesheet" href="style.css">

Também é possível escrever CSS direto dentro da página com uma tag <style> no <head>, ou aplicar um estilo pontual num elemento com o atributo style="...". Mas usar um arquivo separado, como o style.css deste projeto, é o jeito mais fácil de manter organizado.

Sintaxe básica

Uma regra de CSS segue esse formato:

seletor {
    propriedade: valor;
  propriedade: valor;
}

Por exemplo, para deixar todos os parágrafos azuis:

p {
    color: blue;
}

Principais seletores vistos nessa aula

  • tag - seleciona todos os elementos daquela tag, ex: p pega todo mundo <p>
  • .classe - seleciona elementos com class="classe"
  • #id - seleciona o elemento único com id="id"
  • * - seleciona todos os elementos da página

Exemplo prático

Este próprio site usa um arquivo style.css compartilhado. Repare, por exemplo, como os blocos de código acima aparecem com fundo cinza - isso vem de uma regra parecida com esta no style.css:

code, pre {
  background: #f4f4f4;
  border-radius: 4px;
}
