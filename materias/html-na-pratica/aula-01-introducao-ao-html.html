Aula 01 - Introdução ao HTML

O que é HTML

HTML (HyperText Markup Language) é a linguagem usada para estruturar o conteúdo de páginas web. Não é uma linguagem de programação: é uma linguagem de marcação, usada para dizer ao navegador o que é cada parte da página (um título, um parágrafo, uma imagem etc.).

Estrutura básica de um documento

Todo documento HTML segue mais ou menos essa estrutura:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Título da página</title>
</head>
<body>
  <h1>Conteúdo visível aqui</h1>
</body>
</html>

Principais tags vistas nessa aula

  • <!DOCTYPE html> - avisa o navegador que é um documento HTML5
  • <html> - elemento raiz da página
  • <head> - informações que não aparecem na tela (título, charset, links)
  • <body> - tudo que é exibido para quem visita a página
  • <h1> a <h6> - títulos e subtítulos, do mais ao menos importante
  • <p> - parágrafos de texto

Minhas anotações

  • HTML: estrutura textos, criar links, imagens, vídeos, etc...
  • Hypertext: Markup Language -> Linguagem de marcação de texto
  • Tag de link (<a>)
  • Tag de imagem (<img>)
  • Tag de vídeo (<video>)

Atributos: adicionar informações e configurações a uma tag

Atributos são informações extras escritas dentro da tag de abertura, no formato nome="valor". Eles configuram o comportamento do elemento sem mudar o texto que aparece na tela.

<a href="https://exemplo.com" target="_blank">Ver site</a>

Nesse exemplo a tag é <a>, o texto visível é "Ver site" e os atributos são dois:

  • href - para onde o link leva. Sem ele, a tag <a> não vira link de verdade.
  • target="_blank" - abre o destino em uma nova aba.

Atributos que aparecem com mais frequência

  • href - endereço de destino de um link (<a>).
  • src - caminho do arquivo a ser carregado, em <img> e <video>.
  • alt - texto alternativo da imagem, lido por leitores de tela e exibido se a imagem não carregar.
  • class - dá um nome ao elemento para ser estilizado pelo CSS. Pode se repetir na página.
  • id - identificador único na página.
  • lang - idioma do conteúdo, como o lang="pt-BR" lá no topo desta página.

Um exemplo de cada

<img src="foto.jpg" alt="Foto da minha mesa de estudos">
<p class="destaque">Parágrafo que o CSS vai pintar diferente</p>
<section id="introducao">Trecho com identificador único</section>

Detalhe de segurança em links externos

Sempre que usar target="_blank", acrescente também rel="noopener noreferrer". Sem isso, a página aberta na nova aba ganha uma referência para a sua e consegue manipulá-la — é um golpe conhecido como tabnabbing. Repare que os links da seção anterior desta aula já seguem essa 

<a href="https://exemplo.com" target="_blank" rel="noopener noreferrer">Ver site</a>
